## 🚀 Overview

Python Quiz Challenge ek interactive aur high-stakes technical assessment application hai jo user ki core aur advanced Python programming skills ko test karti hai. Is project ko do alag interfaces ke sath implement kiya gaya hai: ek dynamic, sleek Web UI (index.html) aur ek lightweight Command Line Interface (PythonQuiz.py).

> ⚠️ Warning: Sudden Death Rules apply! Ek bhi galat jawab dene par game seedhe Game Over ho jayega. No second chances!

---

## ✨ Core Features

* **Sudden Death:** One wrong answer triggers an immediate Game Over[cite: 1, 2].
* **Weighted Scoring:** Earn +1, +2, or +4 points based on question difficulty[cite: 1, 2].
* **Dual-Interface:** 
    * **Web UI (index.html):** Modern browser interface with smooth CSS gradients and instant feedback[cite: 1].
    * **CLI Mode (PythonQuiz.py):** Lightweight terminal-based script for quick execution[cite: 2].

---

## 🛠️ Project Structure

├── index.html        # Modern frontend application (HTML5, CSS3 Variables, ES6 JavaScript)
└── PythonQuiz.py     # Terminal-based interactive script (Python 3.x)

---


## 🏃‍♂️ Steps to Run

### 1. Web UI Version (Browser)
* Open index.html directly in your browser or run:
  
  # macOS
  open index.html
  # Windows
  start index.html
  
* Click Start Challenge to begin[cite: 1].

### 2. CLI Version (Terminal)
* Run the script in your terminal:
  
  python PythonQuiz.py
  
* Enter numbers 1-4 to submit your answers[cite: 2].


## 📊 Rules & Scoring Layout

| Questions Range | Difficulty Level | Points Per Question | Core Topics Covered |
| :--- | :--- | :--- | :--- |
| Q1 - Q5 | Beginner | 1 Point | Basic Functions, Comments, Basic Loop Keywords |
| Q6 - Q10 | Intermediate | 2 Point | Modules, Boolean Outputs, List Methods, Exception Handling |
| Q11 - Q15 | Advanced | 4 Point | Generators (yield), List Comprehensions, Dictionaries, Tuple Syntax |
